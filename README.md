# Craftium 3D: Caminho dos Campeões

Jogo 3D em navegador com temática esportiva, mundo voxel e desafio final em portal. O jogador percorre um caminho marcado por bandeiras, explora o cenário em primeira pessoa e enfrenta uma sequência de perguntas em um quiz ao atingir o portal final.

## 🎮 Como jogar

1. Abra o arquivo `index.html` em um navegador.
2. Digite o nome do jogador.
3. Clique em **ENTRAR NO CAMINHO**.
4. Siga pelo caminho até o portal final.
5. Responda corretamente às perguntas para acumular pontos.

## 🧩 Tecnologias

- HTML5
- CSS3
- JavaScript
- Three.js
- Web Audio API

## 🚀 Funcionalidades

- Mundo 3D voxel estilizado
- Caminho com bandeiras dos times
- Portal final com transição para quiz
- Sistema de pontuação e vidas
- Controle por teclado e toque
- Layout responsivo para navegador

## 📁 Estrutura

- `index.html` — jogo principal
- `three.min.js` — biblioteca Three.js local
- `Traba01.py` — validação inicial do ambiente
- `Inicio.md` — documentação inicial

## ▶️ Executar localmente

Você pode abrir diretamente o arquivo HTML no navegador.

Se preferir servir localmente via Python:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000/
```

## 🏆 Objetivo

Chegar até o portal e responder corretamente às perguntas para completar a jornada dos campeões.
